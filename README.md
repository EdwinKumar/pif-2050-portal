# Blue Pacific 2050 Strategy - Regional Intelligence Portal

An interactive web dashboard and intelligence portal designed for executives, directors, and regional stakeholders to monitor, analyze, and query the **2050 Strategy for the Blue Pacific Continent**.

---

## Key Features

* **Executive Dashboards:** Interactive visualisations tracking completion rates, resource mobilisation targets vs. secured capital, and CROP lead agency distributions.
* **NLM / AI Data Query Assistant:** Natural language prompt interface enabling directors to ask questions and generate dynamic data subsets and charts.
* **Multi-Dimensional Matrix & Drill-Down:** Filterable table view supporting dynamic sorting, column toggling, and 1-click CSV exports.
* **Multi-Source Data Ingestion:** Connectors supporting embedded data, uploaded Excel / CSV files, and REST API integration with SPC's Pacific Data Hub.
